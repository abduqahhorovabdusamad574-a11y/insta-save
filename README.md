# Insta-Save — Telegram Media Downloader Bot

Asynchronous Telegram bot for downloading social media videos/audio with speech recognition and an analytics dashboard.

## Tech Stack

- **Bot Framework:** Python, `aiogram 3`, `aiohttp`
- **Media & Audio:** `yt-dlp`, `imageio-ffmpeg`, `SpeechRecognition`
- **Modules:** `main.py`, `downloader.py`, `analytics.py`, `dashboard.py`
- **Deploy:** Render (`render.yaml`)

## Local Setup

```bash
pip install -r requirements.txt
python video_downloader_bot/main.py
```
